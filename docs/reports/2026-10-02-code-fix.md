日期：2026-10-01。范围：作者试玩 V1a 包时选牌界面看不到牌（阻断），以及把所有工具交接进仓库。附 itch 包 `overexposed-07b67a1.zip`（不入库）。

## 1. 修复：选牌界面看不到牌

- **原因**：选牌和赛季之门的面板、牌组查看器、错误提示都画在 `.desk` 里面，桌面的样式作用到了它们身上：
  - 手牌的 `.desk .card`（`position: absolute; top: 490px`）把每张候选牌推到了舞台下方；
  - `.desk *` 和 `.desk button` 的重置去掉了面板按钮的边框和底色。
- **修法**：
  - 这些朴素界面改成 `.desk` 的兄弟节点，仍在 `.stage` 里，自带遮罩 `.screen-over`；
  - 手牌的 CSS 全部限定到 `.desk .hand`：26 条 `.card` 选择器、54 条 `.f-` 选择器。
- **其他界面**：逐个查了标题、制作人员、经纪人选择、选牌（3 张、4 张、加抽后、刷新后）、牌组、赛季之门、最后一扇门、结局。
  - 赛季之门和牌组查看器原来也在 `.desk` 里，按钮样式被同样重置，但没有被推出舞台；同一处改动一并修好。
  - 其余界面没有碰撞。

- **顺手修的两处**：
  - 溢出审计试剧本时会替换 React 的节点，导致审计中的应用崩溃（只在审计里出现，玩家不会遇到），已改为原样放回。
  - **Firefox 检查偶尔卡死**，三次。原因在 Firefox 自己的日志里：这台 Windows 机器上它的沙箱有时起不来标签页进程（`Failed to launch tab subprocess`），约 10–25 次启动有一次，那个标签页什么都加载不了。驱动改为：
    - 首个标签页 8 秒内没起来就重开浏览器（最多三次）；
    - 测试配置里关掉 Fission，加载游戏时不再起新进程；
    - 关闭时结束整棵进程树：原来只杀启动器，会留下孤儿进程；
    - 浏览器不应答时检查直接失败并报出是哪条命令，不再无限等待。
  - 连续 40 次启动：0 卡死，3 次自动重开。
