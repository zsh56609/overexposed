## Part D — 剪贴簿和颁奖夜

- **同一尺寸**：书高 580（height，不是 min-height），两页一样；结局页顶部不变，下面多出空间。check:overflow 在三种尺寸下检查两页：书高 580、页面在书内、书在舞台内——结局页下方余 84 px，奖项页 24.6 px（即内边距）。
- **翻页**：两页放在标题下同一个网格单元里，旧页滑出、新页滑入，同时重叠：28 px、240 ms、cubic-bezier(.2, .7, .2, 1)，各自淡入淡出。从结局到奖项，旧页向左离开、奖项从右边进来；反向则镜像。标题在点击时就变。声音是 `cue('open')`，每次翻页一次，点已打开的标签没有声音。翻页中途再点，会结束正在进行的翻页并开始下一次。离开的页面不接收输入（pointer-events none、aria-hidden），滑出结束后从 DOM 移除。减弱动效：150 ms 交叉淡化、不移动；关闭动效：立即切换，声音照常。**做法上**我用 Web Animations API 播放翻页：面板的减弱动效规则把 `.scr *` 的 animation-duration 压到 .01 ms，用 CSS 动画的话 150 ms 的交叉淡化会被吃掉。
- **悬停**（只在有悬停的指针设备上，0.16 s ease-out，无声）：数值全部按你给的写进了 CSS。抬起和放大用 `translate`、`scale` 属性，不用 `transform`：这样能叠加在颁奖夜揭晓时保持的 transform 和剪报自身的倾斜上。减弱或关闭动效时只保留灯光和颜色，不抬起也不放大。
- **check:interactions 新增一项**（Chromium，真实指针，三种尺寸）：从 desk-states 的 awards:4 用真实输入点最后一扇门、在完整动效下进入颁奖夜，依次悬停牌匾、box 的一行、头版和两个气泡；再从颁奖夜打开剪贴簿，悬停剪报、空位、已得奖项和未得奖项。检查完整动效下 translate 或 scale 生效、减弱时不生效，颜色两种模式下都生效，元素的布局框不移动。**两处安排**：这项要放在长按测试之前跑，因为长按会打开触摸模拟，之后页面不再匹配 `(hover: hover)`；手机尺寸从一开始就模拟触摸、没有悬停，在那里它检查的是“什么都不动、不变”。
