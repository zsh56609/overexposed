### Part A — 地基

- **舞台**：唯一的 1280×720 舞台现在裁切（`overflow: hidden` + `clip`），场景不会画到舞台外。新样式都在 `.desk` 下，旧的朴素界面都在 `.plain` 下，互不干扰。
- **字体**：Playfair Display（正体 + 斜体）和 Libre Franklin，可变字体，自托管为 WOFF2（`ui/fonts/`）。没有新依赖、运行时不下载：`tools/woff2.ts` 把原版 TTF 包进 WOFF2 而不改动表数据，并逐字节校验还原。字体数据未改、未子集化，按 OFL-FAQ 可以保留原名（Playfair 有保留字体名）。许可证与声明随字体发布（`ui/fonts/OFL.txt`），标题页新增 Credits 画面，`CREDITS.md` 供 itch 页面用。
- **色彩变量**（`ui/desk/tokens.css`）：README 的颜色、四季灯光、数值颜色、报纸纸色。
- **唯一的适配层** `ui/desk/model.ts`：把状态和历史转成桌面显示的每个字和数，全部来自 /core 查询和内容；组件只渲染字段、不计算。纯函数，所以 check:preview 能拿它对 /core。
- **桌上那期报纸**：出牌阶段显示"如果现在结束本月会印出的那一期"（已印的报道 + 月末会加的丑闻，后者标 `coming`）；选牌时显示本月到目前为止；赛季之门和年终显示刚印好的那一期。危机外观跟随这一期的 frenzy。
- **/core 新增**（只读、不影响 sim）：`issueNow`、`boxOffice`（有种子、不用游戏 RNG）、每条头条照片的计数 `PageItem.photo`。
- **内容新增**并通过 validate、写进 content-schema：`rules.seasons`、`majors[].note`（便利贴颜色）、`papers[].issue`（期号）、`press.boxOffice`，以及每份报纸的桌面文案键。
- 报头耳朵、标语、期号标签、栏目标签、图注、道具上的字、卡面抬头等**用的是样稿里的原文**并入 en.json；十个片名是样稿的示例，保持 `TODO(prose)`；玩家自己的电影 *One Year* 是 README 的。
- 与 README 的出入：无。取舍：Marquee 的右栏在头条是对手、丑闻或玩家成名前的报道时放照片，否则放票房（样稿的做法）。

### Part D — 报纸（§2、§7）

- 按 README 和样稿：三份报纸立在桌上，真实新闻纸质感，报头和两耳、日期行（日期、期号、标语）、头条（栏目、标题、导语、照片或票房）、下面三条。名字来自内容；logo 的字形（b-side 小写、MARQUEE 加宽大写）由样式实现。
- **/core 的头版报纸站在前面**；点后面的报纸（或 Enter/空格）拉到前面，这个选择保持到这一期或其头版报纸改变为止。切换只重渲染报纸——实测所有 DOM 变动都在报纸内。
- 标记我的报道（设置在 V2，默认开）：玩家的报道红线、对手的紫线、票房里玩家的电影也有红线。
- **照片**：样稿的八个场景，每个场景三种画法——原图、镜像、拉近重构图，人群/雨雪/灯光/路人按种子错位；街景按这一期的季节画；狗仔照用红色双色调。洗牌袋用 /core 的计数，**同一份报纸不会连续两个月用同一张照片**（check:preview 在每局检查）。每张首次需要时绘制（约 7ms）并缓存。用自己写的模糊代替 canvas 的 filter（WebKit 不支持），各浏览器画出同样的图。片场照片里导演椅上的 "DIRECTOR" 也改成了文案键。
- **出入 1**：去掉了样稿 B-Side 玩家单曲下面的 ★★★★☆——这是个数字，而游戏里没有评分可给它（也许可以按 craft 档位给？请你决定）。
- **出入 2**：朴素的信息流已移除，桌上只有本月这一期；往月的报纸要等 phase 4 的年度回顾。
- **待你决定**：§7 与 /core 头版平局规则的冲突（见 §0 第 1 条）。

### Part E — 桌面、手机和经纪人（§4、§5）

- 按 README 和样稿：平放在桌面透视里的赛道道具（音乐：两张不同的乐谱；影视：剧本和张开的场记板；名人：GLOSS 杂志；未确立：无），螺旋笔记本和铅笔，狂热时三张红色剪报和手机；立在桌上的节拍器（音乐）、化妆刷筒（名人）或马克杯（未确立），带接触阴影；狂热时两个揉皱的纸团，形状各异、由本局种子决定。
- 笔记本那页是玩家最近一条"安静"的台词；剧本是当前名气档当季的那一场（2c 的内容）。
- 节拍器是样稿的引擎：默认摆动（2.4 秒，狂热 1.3 秒），点击后走完这一摆再缓回中间停住，再点从中间以渐大的摆幅开始；"减少动态效果"时默认停住。
- **手机**：没有角标；锁屏每条通知一根条——本月经纪人消息（蓝）和狂热时的媒体（红），最多 6 条；时间是玩家本地时间、按其区域格式、不带 AM/PM、每 15 秒刷新；狂热时屏幕发红、每几秒震一下。**不用 `Math.random()`**：震动只摇和亮，不加通知条。
- **气泡**：本月消息，每条两个气泡。**出入**：标签用经纪人的**名**（"Marguerite · Manager"，与样稿一致）——全名会压到镜框右侧灯泡的光晕上看不清。点气泡弹出 ❤️ 😂 👍（狂热 💔 😭 👍），回应按"某月第几条消息的第几个气泡"记，不按文字；再点同一个取消，点别处关闭。只是 UI 状态。
- **README 与样稿的小出入**：README 说名人赛道是"a brush cup"，样稿还多了一本平放的 GLOSS 杂志——我按样稿两个都放。

### Part F — 手牌（§6）

- 按 README 和样稿：以 x=540 为中心的扇形，间距 150（超过 5 张为 128），最大倾斜 8°、中间抬高；悬停上抬 13px、倾斜减到 60%、放大 1.012、延迟 70ms、0.42 秒；固定锚点（名字 18px、数值 70px、风味文字 108px）；超过 1 个行动才在右上角显示灯泡；十一种牌面来自内容的 `face` 字段（头像照是网点画）；END TURN 在右下，狂热时变红。
- **抽牌让手牌变多时**，扇形收紧，永远碰不到 END TURN（最宽 960px：8 张牌间距 111px）。
- **数值**（0.3）：图标 + 数字、资源颜色；深色牌面更亮、粉色光面更淡、金箔更深；钱赚绿、花红；"Draw N"。**出入**：卡上的 craft 图标跟状态栏一样按已确立赛道（样稿按牌所在的赛道）——同一种资源同一时刻只有一个图标。
- **README 没覆盖、我补的三处**：卡设置的旗标也算数值，用旗标自己的标签（"Went viral""Signed to a label"）；有使用条件的卡在数值下面加一行要求（"Needs Hype 25+"）；条件规则超过两行时把风味文字往下推。
- **丑闻牌**：红底、白色虚线边、✕、数值行 "Can't be played"、手里的那句作风味文字、规则（抽到时、月末）放在下面。点它会抖一下并在桌面中间提示；行动用完时点任何牌也这样；条件不满足的牌抖一下并弹出预览说明原因。
- **预览**（悬停、长按、键盘）：仍是原来的预览内容，改成新闻纸样式，放在手牌抬到最高处的上方，不挡其他牌名。
- **出牌暂时无动画**：牌离开扇形、扇形立刻重排——样稿里剩余牌滑过去合拢的过渡属于 V1b，我没带过来。
- 其他：数字的负号统一改成真正的减号（U+2212，参考图就是这样）；界面上残留的 "slot" 都改成了 "action"（2c 已定名）。

| 选经纪人 → 桌面首帧（含三张照片绘制） | 149–150 ms | 430–442 ms |
| 拿一张牌 → 手牌出现 | 14 ms | 46–62 ms |
| 鼠标来回扫过手牌（约 1,460 帧） | p95 7.1 ms，最大 7.8 ms，0 帧 > 20 ms | 最大 13.9 ms，0 帧 > 20 ms |
| 连续切换报纸 12 次（约 1,090 帧） | p95 7.1 ms，最大 7.7 ms，0 帧 > 20 ms | 最大 7.7 ms，0 帧 > 20 ms |

- 单张照片首次绘制约 7ms，之后走缓存；头像牌那张 27ms。
- 适配层单次构建最坏 5.4ms。
- 验收时把报纸的位置从 left/top 改成 transform 后，12 次切换引起的重排从 954 次降到 73 次。

### 4.4 浏览器及其差异

- **Chromium**（Chrome，无头，CDP）：全部检查通过。
- **Firefox 142**（无头，WebDriver BiDi，没有新依赖）：审计和交互全部通过。差异：
  - 手机时钟按浏览器区域格式：本机 Chromium 是 12 小时制 "3:47"，Firefox 是 24 小时制 "04:05"——符合"像玩家自己的手机那样显示"。
  - **切换报纸原先会掉帧**（p95 31ms、93 帧超过 20ms）：诊断是后排报纸的 `filter: brightness()` 过渡；改成等效的半透明遮罩后 p95 6ms、0 帧超 20ms，Chromium 看起来完全一样。
  - 扫手牌时约 1–2% 的帧落到 32ms（多次测量有波动），Chromium 没有。无头 Firefox 用的是软件渲染，真机 GPU 下未验证。
  - 无头 Firefox 冷启动首次绘制约 2.1 秒，不代表真实浏览器。
- **WebKit**：没法在本机测。已加的兜底：`overflow: clip` 前加 `hidden`、`-webkit-backdrop-filter`、`:focus-visible` 判断不再在不认识它的浏览器上抛错。**已知风险（本轮之前就存在）**：代码里用了 `Array.prototype.at` 和 `Object.hasOwn`，Safari 15.4 以前的版本会直接报错。
