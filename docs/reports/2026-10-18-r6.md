  - build ✓（在干净导出里，没有警告）；typecheck ✓。
  - validate：0 个错误，27 条警告，全是已砍掉的“每局一次”的变体组：4 个季节开场白（opener:1–4）、1 个开场（opening）、8 扇门、14 个小结局。没有未写的文字。

  - check:preview 300 局 ✓：20,629 个状态、35,395 次出牌、1,754 次事件；见报约定 ✓。
- **验收中遇到的情况**（不是代码问题，没有改任何东西）：check:motion 失败了三次，每次在不同的地方，都没有控制台错误。
  1. Chrome 800×450 第一次：第 201 次加载时浏览器不再应答（“no answer from the browser in 2s”），15 秒内游戏没准备好。
  2. Chrome 800×450 重跑：预览输入的“移动”一步报“busy card hover”。鼠标移到 lay_low 时出牌已经放完、桌面空闲，所以预览照常出现。我按同样的步骤单独测了十次：悬停检查在点击后 408–455 ms，桌面要到 940–957 ms 才空闲，其间一直是忙的，没有闪成空闲。要失败，浏览器得在这几步之间卡住半秒以上。
  3. WebKit 844×390：牌堆输入在 bigHand 的 full 模式开始前，等手牌动画停下等了 5 秒仍没停（“the fan never settled”）。同一步在其他八个配置、R5 的九个配置都通过。
  - R6 不影响回放：回放是静音的，环境声在回放里本来就不会启动。第三次运行期间我查过负载，机器上同时有一个占用约一个核和显卡的程序。
  - 这三个配置（Chrome 800×450、前两次都没轮到的 Chrome 844×390、WebKit 844×390）各自单独重跑，全部通过；其余六个配置在第一次或第三次运行里就通过了。
